# Web Automation Bot: Scrape, Save, Send

🔹 Scrapes real-time data from [insert website]  
🔹 Saves it as a CSV and uploads to Google Sheets  
🔹 Emails the data to a user (auto-attachment)  
🔹 Includes error logging + modular structure

## Tools Used:
- Selenium
- Google Sheets API
- smtplib
- Python CSV & Logging modules

## Ideal For:
- Business owners
- Data analysts
- E-commerce reports
